# Cover Images for Pixify

هذا المجلد يحتوي على صور الغلاف للمشروع.

This directory contains cover images for the project.

---

## الملفات المطلوبة / Required Files

### 1. Repository Banner (في README.md)
- **الاسم / Name:** `pixify-cover.png` أو `pixify-cover.jpg`
- **الحجم الموصى به / Recommended Size:** 1200x400 pixels (نسبة 3:1 / 3:1 ratio)
- **الاستخدام / Usage:** تظهر في أعلى صفحة README الرئيسية

### 2. Social Preview (للمشاركة على وسائل التواصل)
- **الاسم / Name:** `.github/social-preview.png` أو `.github/social-preview.jpg`
- **الحجم الموصى به / Recommended Size:** 1280x640 pixels (نسبة 2:1 / 2:1 ratio)
- **الاستخدام / Usage:** تظهر عند مشاركة المستودع على Twitter, Facebook, LinkedIn, etc.

---

## كيفية الاستخدام / How to Use

1. قم بإنشاء أو تحميل الصور بالحجم الموصى به
2. ضع `pixify-cover.png` في مجلد `assets/`
3. ضع `social-preview.png` في مجلد `.github/`
4. GitHub سيتعرف عليها تلقائياً

---

1. Create or download images with the recommended sizes
2. Place `pixify-cover.png` in the `assets/` folder
3. Place `social-preview.png` in the `.github/` folder
4. GitHub will automatically recognize them

---

## ملاحظات / Notes

- استخدم صيغة PNG للصور مع نصوص أو شعارات
- استخدم صيغة JPG للصور الفوتوغرافية
- تأكد من أن الصور واضحة ومقروءة على خلفيات فاتحة وداكنة

---

- Use PNG format for images with text or logos
- Use JPG format for photographic images
- Make sure images are clear and readable on both light and dark backgrounds
